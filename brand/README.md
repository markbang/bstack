# bstack brand

The mark is a lowercase **b** sliced into three stacked layers, with a squared bowl.

## Mark

| File | Use |
| --- | --- |
| `logo/bstack-mark.svg` | `currentColor` — inline it to inherit the text color |
| `logo/bstack-mark-teal.svg` | baked accent, for dark backgrounds |
| `logo/bstack-mark-ink.svg` | baked ink, for light backgrounds |
| `logo/bstack-mark-white.svg` | baked paper white |
| `logo/bstack-app-icon.svg` | squircle app icon |
| `logo/bstack-favicon.svg` | favicon |

## Lockups

`logo/bstack-lockup-horizontal.svg` (mono), `-dark.svg`, `-light.svg`, plus the same three for
`bstack-lockup-vertical`. The wordmark is **Inter Bold** at −1.2% tracking, outlined to paths.

## Icons

`icons/` holds `favicon-{16,32,48,64,128,256}.png`, `favicon.ico`, `icon-{16,32,64,128,180,256,512,1024}.png`,
`icon.icns`, and lockup rasters.

## Palette

| Token | Value |
| --- | --- |
| Accent | `#6ee7d8` |
| Ink | `#0a0a0b` |
| Panel | `#0f0f13` |
| Paper | `#f4f4f5` |

## Note

SVGs default to `currentColor`. `<img>` does not inherit it, so use the baked variants
(`-teal`, `-ink`, `-white`) or inline the SVG.
